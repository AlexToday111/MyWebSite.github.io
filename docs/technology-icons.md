# Project technology badges

`public/icons/project-stack/` contains variants used only by project badges. Assets in `public/icons/stack/` and other sections are unchanged.

Go, Docker, Prometheus, Java, Python, MySQL, FastAPI and Next.js use colored originals from [Devicon](https://github.com/devicons/devicon). Downloaded from `https://raw.githubusercontent.com/devicons/devicon/master/icons/`:

- `go/go-original-wordmark.svg`
- `docker/docker-original.svg`
- `prometheus/prometheus-original.svg`
- `java/java-original.svg`
- `python/python-original.svg`
- `mysql/mysql-original.svg`
- `fastapi/fastapi-original.svg`
- `nextjs/nextjs-original.svg`

The [Devicon MIT license](licenses/devicon.txt) is included. Brand marks remain the property of their respective owners.

Other variants preserve the existing vector paths and colors with only outer square tiles removed. TypeScript and Nginx keep their existing letter marks in their brand colors. JWT and Kafka include monochrome light/dark variants for legibility. ViewBoxes have consistent transparent margins; artwork is not stretched or cropped.
