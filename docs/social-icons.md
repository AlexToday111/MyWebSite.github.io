# Social icon sources

`public/icons/social/leetcode.svg` is the unmodified LeetCode symbol from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/leetcode.svg), downloaded on 2026-10-27 from https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/leetcode.svg.

It is rendered as a local SVG mask so the original geometry stays unchanged while the existing card color controls its orange default and white hover/focus states. Simple Icons distributes icons under CC0; brand trademarks remain with their owners.
